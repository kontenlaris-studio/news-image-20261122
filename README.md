A program that draws one front-page poster — "THE WORLD IN A DAY" — summing
up the world news of Sunday 22 November 2026 in a single 1024×1024 PNG:
a drone strike on homes near Kyiv, a Russian cargo ship ablaze off Finland,
the COP31 draft that omits "fossil fuels", the Banten factory fire, the
capture of cartel boss "El Chapo Isidro", and the Bayelsa funeral-boat
disaster. Every story was cross-checked in at least two independent reports
before it was put on the page. The poster is drawn procedurally with Pillow
— no image files, no network, byte-identical on every run.

## Run it

```sh
python3 main.py
```

Writes the validated artwork (PNG, ≤1 MiB, 1024×1024) to `/output/entry.png`.
